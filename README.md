### ⚔️ CutCap vs CapCut

| Feature | CapCut (2026) | CutCap |
| :--- | :--- | :--- |
| **4K Export bez vodenog žiga** | ❌ Pro Paywall | ✅ Zauvijek Free |
| **Auto Captions** | ❌ 5 videa/mj free | ✅ Neograničeno, lokalno (Whisper.cpp) |
| **Speed Curve, Keyframes, Stabilizacija** | ❌ Pro | ✅ Otključano |
| **Privatnost** | ❌ Upload na cloud | ✅ 100% Offline na tvom PC-u |

### 🚀 Instalacija za 10 sekundi

**Windows:** `winget install cutcap`
**Mac:** `brew install cutcap`
Ili skini `.exe` / `.dmg` sa [Releases](https://github.com/msunomusic-hash/cutcap/releases)
